# Upstream sync 2026-03 — NextGIS Mobile 3.0.2

Официальный `upstream/master` на момент fetch указывал на `a2e1748` (`versionCode` 173). В root
были влиты два upstream-коммита, в `maplib` — ISO dateformat и исправления sync geometry, в
`maplibui` — обновление таблицы атрибутов после редактирования.

## Результат merge

| Репозиторий | Merge SHA | Примечание |
|---|---|---|
| `maplib` | `519c68a` | ручной конфликт `SyncAdapter`: сохранён layer-fill guard, добавлены upstream sync logs |
| `maplibui` | `e35d7b5` | merge без конфликтов |
| root | `35ece00` | версия 173/3.0.2.1, сохранены flavors и схема имени APK |

В `OfflineSyncIntentService` объединены fork try/catch и upstream log. Указатели root после цикла:
`maplib` → `519c68a`, `maplibui` → `e35d7b5`.

## Принято и оставлено на контроль

Полностью приняты изменения NGW POST/PUT dateformat, sync geometry, attributes table и root sync.
Вручную объединены `maplib` sync adapter, offline sync service и build version/flavors.

На контроль были оставлены расхождение публичного 173 с упоминавшейся сборкой 174, ручная регрессия
walk/GPS/GPX/marker/multipolygon/demo/help и отдельная проверка `easypicker` pointer. Историческая
рекомендация о «сборке не запускалась» больше не актуальна: текущий build workflow описан в
[workstation-and-build.md](../../runbooks/workstation-and-build.md).

# Выбор пользователя

Пользователь подобрал параметры в интерактивном сравнении с прежним APK и
попросил применить их ко всем трекам, затем снова собрать локальный Lisa Release
без публикации. Тестовые прогоны в этом цикле он явно разрешил пропустить.
Объём относится к MOB-01; очередность других пунктов дорожной карты не меняется.

| Параметр | Выбрано |
|---|---|
| Сердцевина | 1.4 px |
| Затемнение | 73% исходного цвета |
| Ширина свечения | 6.5 px |
| Размытие | 3 px |
| Непрозрачность свечения | 83% |
| Обычные видимые уровни | 2 |

Повторным выбором пользователь увеличил свечение с 4.5 до 6.5 px. Это
уточнение той же настройки; остальные значения сохранены. APK `280b78b`
и его квитанция остаются историческим кандидатом с шириной 4.5 px.

Сравнительный масштаб ×1 и фон не переносятся в Android. Для затемнения каждый
sRGB-канал умножается на 0.27 и округляется: например, #FF1744 → #450612.
Исходный сохранённый цвет используется свечением и выбором цвета; производный
`track_core_color` существует только в rendering feature. Все старые и новые
треки, история и текущая запись получают один стиль. Новых чтений SQLite,
источников или style layers нет; прежнее белое выделение выбранного трека
сохраняется. Схема БД, sync, имена/точки и desktop не меняются.

# Проверка и доставка

Native pixel/style expectations скорректированы под этот выбор; локальные
unit/native/UI тесты сейчас не запускаются по поручению пользователя. Ранее
зафиксированные 887 unit/11 native PASS относятся к предшествующей ревизии и
не являются приёмкой новых параметров. FPS/расход батареи и сходство свечения
с приблизительным browser образцом пока не измерены.

Сборка Lisa Release, чтение production identity/версии из APK, проверка подписи
и SHA-256 завершены: [квитанция APK 280b78b](../history/lisa-local-release-dark-core-2026-10-25.md).

пользователем; merge, установка в рабочую ЛИСУ и публикация не запрошены.

без их слияния. Порядок будущего закрытия зависимостей прежний: maplib #60 Merge

# Синхронизация загруженных проектов

Откройте «Настройки» → «Общие» → «Синхронизация». Пункт
«Синхронизировать все проекты» включён по умолчанию. При ручном запуске и запуске
по расписанию обновляются все проекты, уже загруженные на устройство. Открывать
их по очереди не требуется. Новые проекты из ВебГИС автоматически не загружаются.

Если выключить этот пункт, очередная синхронизация охватит только открытый
проект. Отдельная команда синхронизации слоя всегда относится к открытому проекту.

Для автоматического запуска включите синхронизацию нужной учётной записи и
задайте её период в настройках подключения. Каждая запись сохраняет свой период;
выключенные записи по расписанию не запускаются. Ручная кнопка выполняет явное
обновление и не требует включённого расписания. Android может отложить фоновый
запуск при ограничениях питания или сети.

Проекты обновляются последовательно: отправляются локальные изменения и вложения,
загружаются данные, формы, справочники и настройки проекта. Открытая карта остаётся
на экране. Незавершённая форма сохраняет введённые значения и свой набор справочников.
Смена проекта во время синхронизации предлагает прервать её и ждёт безопасного
завершения текущей операции.

Если один проект не обновился, остальные продолжают синхронизироваться. После
ручного запуска сообщение перечислит проекты, для которых нужно повторить попытку.
Правки остаются на устройстве. После прерывания или перезапуска приложение сохраняет
незавершённые операции для повтора; уже отправленные изменения не создаются заново.
Отмена может потребовать времени, если сервер уже принял запрос на запись.

Обновление приложения включает новую настройку сразу. Версии приложения,
расписания подключений и состав загруженных проектов от этого не меняются.

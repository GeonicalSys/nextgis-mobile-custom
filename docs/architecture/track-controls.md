# Треки на карте и в списке

В списке выбранный одиночный трек можно переименовать. Название обрезается по
краям, пустое значение не сохраняется; одинаковые названия допустимы. ID, время,
точки, сегменты и очередь отправки при переименовании сохраняются. GPX берёт
актуальное название из общей базы, как прежде.

Обычный тап выбирает видимый трек через native queryRenderedFeatures. Совпавшие
сегменты одного сеанса объединяются по track_id; несколько разных сеансов дают
выбор по названию. Попадание в видимый точечный объект сохраняет существующий
выбор объектов. Метаданные всех совпавших треков читаются одним снимком.
Редактирование, линейка, азимут и другие инструменты не выбирают
треки. При переходе в инструмент панель закрывается.

Нижняя панель даёт цвет, название, скрыть/показать и удалить. Скрытый выбранный
трек остаётся в панели, в том числе после пересоздания Activity, чтобы его можно
было снова показать. Скрытие не останавливает запись. Удаление требует
подтверждения. Исторический трек удаляется без остановки другого текущего сеанса.
Для текущего сеанса сохраняются pending_delete_track + pending_stop; recorder
дописывает очередь, закрывает и удаляет ровно этот ID в одной транзакции.
Ошибка оставляет намерение для повтора; до успешного удаления оно не очищается.

## Подтверждение остановки

Кнопка карты, меню и Stop в уведомлении открывают один FittedDialogs confirm.
До положительного ответа запись/очередь не меняются; Cancel/Back оставляют
сеанс активным. Notification PendingIntent напрямую открывает неэкспортируемую
TrackStopConfirmationActivity. Durable track_recording_session — UUID
пользовательского сеанса, сохраняемый через recovery/midnight split.
Положительный ответ проверяет UUID, checkpoint pending_stop и лишь затем
отправляет Stop. Старый диалог/уведомление не останавливают новый сеанс.
Уже подтверждённый Stop при SQLite retry не запрашивает согласие повторно.
HyperLog различает map/menu/notification, подтверждение и отмену.

## Цвет и отрисовка

TrackLayer.insert назначает цвет, если при создании он не задан. Палитра из
12 насыщенных оттенков имеет HSV saturation не ниже 80% и контраст к белому
не ниже 2:1; случайный выбор избегает непосредственного повтора последнего
цвета. Цвет сохраняется один раз, а не генерируется при открытии карты.
SharedTrackStore schema 2 однократно раскрашивает прежние SQL NULL цвета.
Используется перемешанный полный цикл 12 оттенков; значения сохраняются в одной
транзакции с версией базы. Поздний импорт старого проекта раскрашивается в
транзакции импорта. Ошибка откатывает всю операцию для повтора. Явно заданные
цвета, включая #5f789c, автоматически не меняются.
Изменение desktop-палитры отложено по указанию пользователя.

Каждый сегмент GeoJSON получает track_id, track_name и track_color. Начальные и
конечные флажки остаются отключены. Общие saved/current sources имеют по одному
проходу свечения (6 px, blur 2, opacity .55), белому выделению (4 px, только
выбранный ID) и чёткой линии (2 px). Число style layers постоянно при росте числа
треков. Данные берутся из прежней общей SQLite; смена GeoJSON/тайлов и протокола
отправки не входит в эту задачу. OpenGL и MapLibre 13.7.1 сохраняются.

## Порядок

Служебный слой «Мои треки» остаётся первым в списке. Native порядок данных:
обычные полигоны/линии/растры → треки → настоящие Point/MultiPoint слои →
временные инструменты → GPS. Для каждого точечного слоя вместе переносятся
тело, ореолы, изображения и подписи, с сохранением порядка слоёв в списке.
Определение идёт по VectorLayer geometry type и source identity; polygon-label
sources и произвольные SymbolLayer не считаются точечными слоями. Точки внутри
растровых серверных изображений отдельно поднять невозможно.

Один общий порядок восстанавливается после полной и lite-загрузки, hot/style
обновлений и перестановки слоёв. Уже правильный стек не перестраивается.

## Проверки

`tools/verify-mobile-tests.ps1 -Scope Related -Area track-controls` проверяет
список/Save/Cancel, цвета в native source, реальные тапы, скрытие/возврат,
пересоздание экрана, совпадающие треки, подтверждение удаления, GPU пиксели и
Point/MultiPoint над линиями. Отдельная native регрессия провоцирует отказ
удаления активного сеанса и проверяет повтор без потери намерения. Русская
панель проверяется в двух темах, portrait/landscape, fontScale 1/1.3/2 и
viewport 320/280 dp. Related feature-editing проверяет прежний редактор.
Диалоги Rename/Color/Delete дополнительно проверяются в 24 профилях native
окна (72 настоящих открытия и нажатия Cancel), с реальной сменой ориентации
Activity и локальными font/density overrides; системные настройки телефона
не меняются.
Related track-followup добавляет Stop/Cancel/Back во всех ручных входах,
stale notification/dialog, split, 24 профиля Stop и native SQLite upgrade.
Разбор сегодняшнего журнала и фактические проверки:

# Завершения после обновления 224

Поручение 27 октября: разобрать предоставленный ng-logs ZIP и GlitchTip.
По словам пользователей, Samsung Galaxy Tab закрывается вскоре после загрузки
карты при перемещении жестами. Модель из коррелированного GlitchTip ANR — SM-X115.

## Возобновление после выключения и новый отчёт69

27 октября пользователь сообщил о возможном выключении компьютера и передаче
тестового APK. Исходники и APK030f303 сохранились. Последний delivery05 оборван
до instrumentation: пустой emulator log и повреждённый console log не являются
результатом теста. При возобновлении не осталось принадлежащих этому прогону
эмуляторов/runner процессов. Три незакоммиченных изменения — собственные
доработки стресс-теста и валидатора; чужая desktop ветка не меняется.

Группа [69](https://apps-geonical.ru/errors/geonical/issues/69) переоткрыта новым
SIGABRT от27 октября14:22:41UTC на Pixel9Pro/Android17. Исходная сборка223,
revision5050495; reporter тоже223. Это не событие с диагностического030f303.
Два прежних события — HONOR/223 от18 октября с libmaplibre и SM-X115/222
от14 октября с libsentry unwind. Группа объединяет abort, а не установленную
единую причину. В новом стеке только libc abort и неизвестный адрес; полезного
caller/native exception message нет. Сбор OS crashing-thread frames и ограниченного
abort message уже реализован в PR82 и входит в переданный APK.

За две минуты до нового abort у того же процесса Pixel поступили два события45:
`heap_headroom` при474656752/536870912 байтах занятого Java heap и `queue_full`
при16 ожидающих запросах/2 workers. Это подтверждённые отказы локального tile
service, не внешний HTTP503. Сам SIGABRT не доказывает OOM или причинность
этих отказов; в момент abort нет достаточного heap/native snapshot. Новое событие68
на том же223 — acquisition без первой GPS координаты/schema2; новая узкая policy
для штатного ожидания уже существует. Срезы45=188,68=35,69=3 прочитаны полностью.

Для69 нужен следующий отчёт после падения и повторного запуска диагностического
APK. Если OS trace недоступен, коллектор сообщает явный статус; Android<30 не даёт
этого fallback. Отсутствие trace или отсутствие повтора не означает исправление.

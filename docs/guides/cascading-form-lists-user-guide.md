# Выбор подрядчика и сотрудников в аудите

В обновлённом приложении с настроенной формой сначала выберите подрядчика.
После этого появятся доступные должности его сотрудников. Выберите должность,
затем сотрудника: список содержит только людей этого подрядчика с этой
должностью. Для второго сотрудника выбор выполняется отдельно.

Должность и сотрудник отображаются отдельными полноширинными полями с подписями
и промежутком. Подписи берутся из псевдонимов полей формы («Должность»,
«Сотрудник»), а при их отсутствии — из псевдонимов слоя. Для старых форм со сдвоенными каскадными элементами приложение
само создаёт такие отдельные поля; обновлять серверный файл ради этого не нужно.

Каждое значение выбирайте явно. Приложение не подставляет первого сотрудника,
даже когда в списке только один человек. Подсказка «Сначала заполните предыдущие
поля» означает, что ещё не выбран подрядчик или должность. «Нет доступных
вариантов» означает, что подходящих записей нет в загруженном справочнике.

При смене подрядчика обе должности и оба сотрудника очищаются. При смене
должности очищается соответствующий сотрудник. Выберите нужные значения снова.
Поля со звёздочкой обязательны. «Нет значения» не считается заполнением;
«не применимо» можно выбирать там, где такой вариант предусмотрен.

После загрузки проекта списки работают без интернета. Незавершённую форму
можно восстановить вместе с выбранными значениями. Обновлённые справочники
используются в новых формах; уже открытая форма и её черновик сохраняют свой
набор справочников.

После сохранения аудита жёлтая точка у его слоя означает, что изменения ещё
не отправлены в ВебГИС. Общая точка на кнопке синхронизации показывает наличие
таких слоёв в проекте. После успешной отправки обе отметки исчезают.

В старом аудите сотрудник может уже отсутствовать в текущем справочнике.
Приложение показывает его как сохранённое значение и сохраняет прежнюю запись.
Если изменить подрядчика или должность, потребуется выбрать сотрудника заново.

Администратор обновляет данные обычной программой «Синхронизация ВебГИС»:
«Проверить изменения» → просмотр плана → «Обновить ВебГИС». Затем на телефоне
нужно успешно обновить проект. Настройки каскада передаются вместе с формой;
отдельно заполнять пары списков в ВебГИС не требуется.

Функция требует обновлённого приложения и формы с настроенными связями.
Штатный веб-редактор и прежние приложения эти связи не выполняют. Не переводите
настроенную NGFP в другой формат через веб-конструктор: администратор должен
снова проверить и обновить её синхронизатором.

Закреплённые вкладки, взмахи и обязательные комментарии описаны в
[руководстве по заполнению форм](form-behavior-user-guide.md).

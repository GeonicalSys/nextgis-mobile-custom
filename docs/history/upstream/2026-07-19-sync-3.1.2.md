# Selective upstream sync 2026-07-19 — NextGIS Mobile 3.1.2

Официальная база проверена на release 3.1.2 / `versionCode` 191: root
`eb5dac154f10`, maplib release pointer `aceea1064759`, maplibui release pointer
`d0af02618`, easypicker `aa7435f74134`. Из-за существенного расхождения Collector,
layer fill, flavors и MapLibre pipeline выполнен selective/hybrid port, а не
полный merge.

Результирующая версия integration cycle — `3.1.2.1`, `versionCode` 192; app и
maplib VERSION_NAME выровнены.

Перед изменениями созданы локальные теги `pre-upstream-sync-2026-07-19-*` на
baseline root `407533be3d85`, maplib `1f632769eb11`, maplibui `18aeb7f2643a`,
easypicker `fba5b0862599`. Рабочие изменения сделаны в ветках
`sync/upstream-3.1.2` root/maplib/maplibui; publish не выполнялся.

## Принятые и адаптированные изменения

| Область | Решение | Результат |
|---|---|---|
| Добавление NGW layer по URL | hybrid | Чистый parser поддерживает NextGIS и self-hosted server path; точечный resolver обрабатывает style parent, account и permissions; UI использует существующий fill/reload pipeline. |
| `MapDrawable` walk/move/null guards | hybrid | NPE guards сохранены вместе с fork rendering; move восстанавливает vertex/middle points, marker и measurement captions. |
| `GeoEnvelope` null serialization | hybrid | Публичные primitive getters не менялись; пустой envelope безопасно пропускает bbox. |
| Typed form values | upstream intent | Сравнение выполняется через `toString()` и покрыто unit tests. |
| Успешный fill без layer | upstream intent + ours | `null` не вставляется, Collector queue/deferred reload остаются без изменений. |
| NGW `data.write` | hybrid | Permission передаётся в fill, edit/push выключены, pull остаётся доступен. |
| Sentry production metadata | upstream | Interaction/view hierarchy выключены, screenshot включён, trace/profile sample rate `0.05`. |
| Easypicker URL slash fix | already equivalent | Fork уже содержит patch-equivalent исправление; новых правок нет. |

## Осознанно не переносилось

- upstream monolithic URL implementation в `MainActivity` и Loader lifecycle;
- удаление/упрощение fork Collector batches, retries, backups и deferred reload;
- upstream flavor/version layout и submodule pointers;
- `KEY_ADDED_OTHERS` form behavior без подтверждённого consumer contract;
- смена return type `GeoEnvelope` getters с primitive на boxed во всём public API.

# Что нового — NextGIS ЛИСА / Белка (форк GeonicalSystem)

Пользовательский changelog без внутренних деталей реализации. Техническая карта отличий находится
в [`docs/reference/fork-customizations.md`](docs/reference/fork-customizations.md), история merge —
в [`docs/history/upstream/`](docs/history/upstream/README.md).

## 3.1.2.7 — 2026-07-30

- Запись трека и «обходом» работает при движении до 160 км/ч; единый GPS-фильтр
  продолжает отбрасывать точки с плохой точностью, устаревшие фиксы и одиночные
  скачки координат. Если включены GPS и Network, приложение предпочитает свежий
  GPS, а Network автоматически использует как резерв при его пропадании.
- Для слоёв-мультиполигонов самопересекающийся контур при сохранении
  автоматически приводится к корректной геометрии; все получившиеся части
  остаются одним объектом с одной формой атрибутов. Исправлено сохранение таких
  контуров после ручного редактирования на карте.
- Защита от потери данных при сбое: запись трека сама возобновляется после
  перезагрузки; незавершённый обход и форма атрибутов предлагают продолжить или
  отбросить черновик; правки геометрии тоже сохраняются как черновик.
- Синхронизация: уведомления sync по умолчанию выключены; ручной запуск без
  лишнего диалога про «ОС»; при ошибке — сообщение с причиной и кнопкой
  «Повторить»; рядом с кнопкой sync показывается индикатор неотправленных
  локальных изменений; вращение кнопки прекращается после фактического завершения.
- Большие Collector-проекты надёжнее загружают параллельные слои; точки появляются
  сразу после импорта или локального включения слоя — без изменения настройки
  видимости на сервере, дополнительной синхронизации и перезапуска приложения.
- Резервные копии слоёв перед разрушительными операциями и сохранение вложений
  после отправки на сервер (без «пустой галереи» до второго sync).
- Выборка линий по реальной геометрии (не по прямоугольнику); кнопка формы
  атрибутов в окне идентификации для редактируемых слоёв.

## 3.1.2.5 — 2026-07-25

- Выборка линейных объектов срабатывает у самой линии (допуск тапа), а не по
  прямоугольнику экстента — тап в «пустом углу» буквы Г больше не выбирает объект.
- В окне идентификации объекта для редактируемых слоёв (галочка Collector /
  политика редактирования) добавлена кнопка формы атрибутов: сразу открывает
  сеанс редактирования слоя и форму ввода.

## 3.1.2.4 — 2026-07-24

- Collector project импортирует `qgis_vector_style` и `qgis_raster_style` как
  read-only raster tile layers с общим порядком относительно vector-слоёв.
- Обновление продолжается автоматически после возврата с Android-экрана
  специального разрешения; повторный ручной запуск проверки не нужен.
- Дефолтный OpenStreetMap Standard aka Mapnik создаётся в каждом Collector
  workspace и остаётся внизу списка без сброса видимости.
- Project-managed Collector-слои редактируются по галочке элемента Collector и
  исходящему направлению синхронизации, а не общему `is_editable`.
- «Мои треки» закреплены наверху списка; Collector batch вставляет слои ниже.

## 3.1.2.2 — 2026-07-20

- Исправлено добавление Веб ГИС в production ЛИСА/Белка: после успешного входа
  Android-аккаунт теперь создаётся с правильным Geonical identity; при системном
  отказе форма не закрывается молча.
- Релизная палитра стала ярче и ближе к лисьей: приглушённые коричневые оттенки
  заменены насыщенными рыже-оранжевыми; зелёная debug-тема не изменялась.

## 3.1.2.1 — 2026-07-19

- Проверка обновлений переведена на новый раздельный репозиторий Lisa/Belka/Debug;
  усилена проверка URL, версии, размера и подписи загружаемого APK.
- Добавлено создание NGW vector/raster слоя по прямому URL ресурса; ссылки на
  QGIS-стиль автоматически открывают родительский слой.
- Для публичного сервера без настроенного аккаунта безопасно создаётся guest
  account — только после проверки адреса, ресурса и прав чтения.
- Слои без права записи открываются read-only и синхронизируются только с сервера.
- Исправлены ложные предупреждения об изменении числовых полей формы, падения в
  Walk/edit flow и сериализация незаполненного bbox.
- Перенос точки теперь сразу обновляет вершины, marker и подписи измерения.
- Снижена доля Sentry performance sampling; отключён сбор interaction breadcrumbs
  и view hierarchy при сохранении crash screenshot.

## 3.0.3.9 — 2026-07-19

- Удалены унаследованные Google Analytics, tracking ID и автоматическая отправка crash-статистики.
- Диагностические логи HyperLog остаются локальными; Sentry допускается только через
  контролируемый Geonical endpoint.

## 3.0.3.8

- Production ЛИСА/БЕЛКА получили приглушённую оранжевую палитру.
- Зелёная тема сохранена только в тестовой `lisaDebug`.

## 3.0.3.7

- Добавлена тихая проверка self-hosted обновлений после свежего запуска при наличии сети.
- Ошибка проверки не мешает открытию карты; найденное обновление показывается в отменяемом диалоге.
- Увеличены безопасные таймауты подключения и скачивания APK.

## 3.0.3.6

- Production ЛИСА/БЕЛКА используют отдельный application ID GeonicalSystem; официальный пакет
  NextGIS Mobile не затрагивается.
- Добавлены ручная HTTPS-загрузка обновления и проверки flavor, package, версии, SHA-256 и подписи.
- Разрешены `lisaDebug`, `lisaRelease`, `belkaRelease`; несовместимые cross-flavor обновления
  отклоняются.

## 3.0.3.5

- Стабилизированы запуск и восстановление записи трека после crash/stale state.
- WorkManager-синхронизация больше не планируется в служебном процессе трекера.
- Добавлен уникальный sync worker на учётную запись и расширена диагностика NGW sync.

## 3.0.3.4

- Расширена MapLibre-стилизация: подписи, opacity, типы линий, маркеры, штриховки и rule-style.
- Смена части настроек стиля выполняется без полной перезагрузки карты.
- Display-only Collector-слои нельзя случайно открыть на редактирование.
- Укреплены batch import, pull sync, fallback повреждённого renderer и crash diagnostics.
- Добавлен district filter по `resmeta.items.district`.

## 3.0.3.3

- Запись трека получила идемпотентную остановку, восстановление и более полные локальные логи.
- Текущий трек показывает GPS lead-preview без записи промежуточной точки в БД.
- Источник положения по умолчанию — GPS и другие сети.

## 3.0.3.2

- Schema mismatch NGW теперь обнаруживает также удалённые на сервере поля.
- Перед автоматической пересборкой сохраняются локальные изменения и позиция слоя.
- Исправлены гонки карты при удалении слоя, восстановление user-location source и refresh в
  `MapFragment`.

## 3.0.3.1 — 2026-05-15

### Из официального NextGIS Mobile

- Рисование линий и полигонов обходом (Walk-by-geometry), включая восстановление после process kill.
- Мгновенная перерисовка слоя после загрузки offline tiles.
- Поддержка одинаковых названий слоёв при отправке в NGW, Q-тайлов `{q}` и сохранение zoom TMS.
- Оптимизирована подзагрузка дочерних NGW-ресурсов.

### Доработки GeonicalSystem

- `.ngrc` после импорта сразу отображается в правильном месте стека без перезапуска.
- Если OSM отсутствует, новый растр помещается вниз пользовательского стека.
- Walk начинается от текущего GPS-положения/anchor, а незавершённая геометрия восстанавливается.
- Start/end флаги треков и автоматическое расширение zoom `.ngrc` намеренно отключены.

## 3.0.2.3

- NGW config из `resource.description` обновляется и для слоёв с `SYNC_NONE`.
- После batch fill карта выполняет bounded reload без обязательного перезапуска процесса.
- Сброс карты использует единый безопасный путь и не оставляет устаревший `MapDrawable`.

## 3.0.2.2

- Исправлены падения при удалении вершины мультиполигона и при закрытии `LayersFragment`.
- Чтение geometry column при NGW sync теперь явно проверяет наличие корректного индекса.

# Upstream sync 2026-05-15 — NextGIS Mobile 3.0.3

Перед merge были созданы теги `pre-upstream-sync-2026-05-15-*`. Upstream tips: root `2371e54`,
`maplib` `d943c07`, `maplibui` `b225a8f8`, `easypicker` `c1bb1fc`; официальная версия —
3.0.3 / `versionCode` 178.

## Основные принятые блоки

- upstream Walk-by-geometry и process-kill restore были объединены с fork pipeline, который начинает
  фигуру от GPS anchor и явно готовит MapLibre session;
- Collector/map hooks, same-name NGW layer fix, refresh offline tiles и `loadChildren(skipSubLoad)`;
- Q-tiles `{q}`, сохранение min/max zoom локального TMS;
- AGP 9.x, Google services 4.4.4, MapLibre 13.0.2, OkHttp 5.3.2 и Gson 2.13.2;
- новые interface hooks `setMapLayersLoaded` и `checkCreateIfNeed`.

## Осознанно сохранённые fork-решения

- `NGWResourceTypeCollector` и Collector import flow;
- отсутствие start/end flag sources у треков;
- fork Walk pipeline вместо upstream single-layer последовательности;
- flavor-specific `APP_NAME` вместо release-wide upstream value;
- версия форка 3.0.3.1 / 179 вместо 3.0.3 / 178.

Крупные ручные конфликты были в `MapDrawable`, `MapFragment`, `IGISApplication`, `Connection`,
`LocalTMSLayer`, `SelectNGWResourceActivity`, `EditLayerOverlay` и `app/build.gradle`. После merge
исправлены переименование map context, walk signatures и два documented interface no-op.

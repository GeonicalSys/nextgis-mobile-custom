# Копирование, сдвиг и поворот объектов

## Копирование в другой слой

При выборе объекта нижняя панель содержит «Копировать в слой», в том числе
для исходного слоя только для чтения. Диалог всегда предлагает другие
редактируемые векторные слои текущей карты, включая скрытые. Совместимость
сохраняет семейство геометрии: точка, линия или полигон. Single можно обернуть
в Multi; обратное преобразование доступно только при одной части. Несколько
частей никогда не обрезаются до первой. Слой назначения становится видимым.

Категория назначения выбирается тем же ChooseFeatureTypeDialog, что при создании.
Затем открывается обычная форма нового объекта с готовой геометрией. До Save
новая строка не записывается; Cancel сохраняет исходный объект. Структура
кольцевых отверстий и составных геометрий сохраняется.

Атрибуты сопоставляются по точному имени поля, независимо от alias. Совпадающие
типы переносятся; FTInteger также допускает безопасное расширение до FTLong
или FTReal. Идентификатор строки и геометрическое служебное поле исключены.
Неподходящие типы не преобразуются произвольно. Выбор категории назначения и
его зависимых родителей/очищенных потомков имеет приоритет над копируемыми
значениями. Формы, required, каскады и scripts используют штатные Save gates.

FeatureCopyDefaults передаёт типизированные начальные значения для обычной/NGFP
формы и JSON скалярных полей, отсутствующих на форме. Последние также попадают
в Save и before-save. Отдельный снимок исходного состояния controls сохраняет
SQL NULL и пустую строку, пока пользователь не изменил значение, даже если
checkbox/counter отображает отсутствие значения как ноль. Nullable даты
сохраняют пустое состояние. Все эти данные входят в существующий durable form
checkpoint и Activity state; копия не привязана к временному MapLibre edit object.

Выбор слоя/категории удерживает source map/layer/feature identity в Fragment state.
Перед открытием формы повторно проверяются исходный объект, карта, права
назначения и совместимость. Отсутствующий источник приводит к понятному сообщению
без вставки. Если point-lock фонового обхода восстановился без черновика и без
контекста выбора копии, он освобождается с предложением выбрать объект заново.
Диалог слоя восстанавливает тему до создания ContextThemeWrapper; выбор слоя
и выбор категории проверяются с пересозданием Activity. Числовые controls
получают Bundle соответствующего типа после наложения категории; int64 для
counter не преобразуется через double.

## Сдвиг и поворот

В режиме редактирования геометрии есть «Сдвиг и поворот». Один палец сдвигает
весь объект; два пальца поворачивают его вокруг центра габарита. Расстояние между
пальцами не масштабирует объект. Камера карты не перемещается. Повторное нажатие
возвращает обычное редактирование вершин; Save и Cancel остаются штатными.

GeometryTransform действует на независимой копии EPSG:3857 и сохраняет все
части, внешние и внутренние кольца и их CRS. Переходы один/два/три пальца
перебазируют жест без скачка. Промежуточные изменения сразу попадают в geometry
journal через default-compatible previewGeometryTransform; один завершённый
жест даёт один шаг Undo. ACTION_CANCEL восстанавливает точный предыдущий
снимок координат, без повторного кругового преобразования CRS. Сохранение
пишет геометрию штатным путём; отмена редактора возвращает исходный объект.
После восстановления черновика доступно обычное редактирование вершин.

BottomToolbar.fitAllActions сохраняет все команды в одной строке без overflow.
При нехватке ширины уменьшаются только размеры icon targets. Расчёт использует
фактическую density и текущие insets, а не физическую xdpi; обычная ширина
сохраняет размер до 56 dp. Полные названия доступны через accessibility/tooltip;
активный режим также имеет полностью вписываемый текст панели.

## Проверка и доставка

Related `-Area feature-editing` запускает проверки на изолированном эмуляторе.
С явным `-PhoneSerial` дополнительно выполняются три неподвижных сценария на
отдельном verification APK. `-PhoneOnly` допускается только для Related с явным
serial: выполняется только разрешённая phone-часть области. Полная проверка
публикации по-прежнему требует Full с обоими устройствами.
После ручной разблокировки runner сворачивает шторку уведомлений. Тест карты
отдельно закрывает стартовое предупреждение обычным Activity lifecycle;
предупреждение имеет собственное UI-покрытие. Системные настройки не меняются.

Native coverage: копирование точки из read-only слоя, фильтр назначения,
отмена выбора, пересоздание выбора слоя и категории, новый Save в SQLite, нулевые/NULL/int64
значения и неизменность источника; реальные MapView gestures для MultiPolygon
с отверстием/двумя частями, неподвижная камера, отсутствие масштабирования,
Undo/Redo, ACTION_CANCEL и сохранение. Component QA проверяет обе темы,
portrait/landscape, fontScale 1.0/1.3/2.0 и ширины 360/320/280 dp.
Unit coverage проверяет преобразования всех шести семейств и совпадение схем.

касаниями кнопки, отмены, строки назначения и Save; оба выбора пересозданы.

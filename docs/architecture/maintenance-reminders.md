# Напоминания о синхронизации и обновлении

Дорожная карта: UX-05. Предупреждения советуют подключиться к интернету,
обновить данные и APK, сохраняя возможность продолжить полевую работу.
Автоматической установки, запуска синхронизации или запрета работы нет.

| Условие более семи суток | Сообщение и действие |
|---|---|
| Последняя успешная полная синхронизация активного проекта устарела | Подключиться и выполнить синхронизацию проекта |
| Успешной проверки manifest обновлений давно не было | Подключиться, открыть приложение и установить предлагаемое обновление |
| Устройство знает о неустановленном обновлении, полный проверенный APK отсутствует | Подключиться без роуминга и открыть приложение; штатный worker скачает и предложит установку |
| Устройство знает об обновлении, соответствующий APK проверен и готов | Установить; при проблемах обратиться в техподдержку. Доступны «Обновить» и «Позже» |

Признак онлайн-проекта — наличие INGWLayer в дереве **активной** карты,
включая группы. Локальная карта, локальные импортированные геометрии, OSM и
треки не требуют sync. Переключение на локальный проект исключает его sync
проверку, даже если раньше был открыт онлайн-проект. Проверка APK остаётся.
Путь карты захватывается до async запроса и сверяется перед показом: старый
проект не должен получить предупреждение поверх новой карты.

Sync clock читается только из ProjectSyncState по canonical map path.
Его обновляет штатный ProjectSyncRunner после **полного успешного** прохода
всех accounts/children проекта и проверки очередей. Частичная отправка,
один слой, ошибка, отмена, успех другого проекта и открытие приложения его
не изменяют. [Основной контракт sync](ngw-sync-and-storage.md).

Отдельный private SharedPreferences `maintenance-reminders` сохраняет дату
последнего успешного запроса проверенного branch manifest (`last_check`) и
первого обнаружения ещё не установленного обновления (`available_since`,
`available_version`). Новое издание и повторная проверка не отодвигают уже
начатый срок. Проверенный manifest с текущей версией убирает withdrawn/update
состояние; установленная версия также очищает перекрытый ею backlog. Только
проверенный локальный APK нужной версии означает «загружено»: partial,
неподходящая версия, повреждённый hash/сертификат не подходят. Чтение готового
APK офлайн не обновляет `last_check`; правила проверки и установки сохранены.

Для истории, которую прежние версии не записывали, начало наблюдения
`first_observed` и `project_observed_<path-hash>` даёт неделю без предупреждений.
Это **не** время синхронизации или проверки; после недели текст честно говорит
об отсутствии подтверждения. Старый достоверный ProjectSyncState используется
сразу. Будущее время после перевода часов назад не считается просрочкой.
Порог строгий: ровно семь суток ещё не «больше недели».

Показ принадлежит foreground automatic update check: карта resumed/usable,
есть фокус, async результат относится к текущей карте. Ошибка сети сохраняет
pending retry и не превращается в успешную проверку после закрытия предупреждения.
Причины объединяются в один диалог. Готовый APK получает тот же текст в обычном
предложении с «Обновить/Позже», без второй копии предложения.
`shown_session`/`shown_at` ограничивают повороты и сетевые retry одним показом
за процесс в течение суток. Новый процесс снова предупреждает; в постоянно
живом процессе следующее открытие через сутки возобновляет automatic check.
Это проверка при открытии, не новый таймер и не дополнительный фоновый job.

Проверки: MaintenanceRemindersTest на API 28/36, интеграция с validated ready
в AppUpdateReadyStateTest и Related `maintenance`. Native проверяет durable
часы и 288 локальных конфигураций диалога: четыре состояния × две темы ×
fontScale 1/1.3/2 × portrait/landscape × normal/320/280 dp. Сообщение сохраняет системный крупный шрифт и прокручивается в ограниченной
области; кнопки закреплены за её пределами. Проверяются полный Layout без
ellipsis, достижение конца прокрутки, высота окна, видимость действий и отсутствие установки
после подтверждения/«Позже». Системные настройки телефона не меняются.
Full смартфона и планшета выполняется после фиксации окончательного кода;
результаты принадлежат [квитанции](../reference/mobile-full-2026-10-25.md).

Для новых длинных сообщений app сохраняет штатный NestedScrollView и полный
системный шрифт. Private ReminderPanels измеряет целиком title/button panels
до выделения остатка сообщению: минимальная высота stacked ButtonBar не
должна обрезать второе действие. Предупреждение стоит первым, версия и release notes — ниже в прокрутке.
Native проверяет обе кнопки внутри окна и сохраняет PNG при 280 dp / 200%.
Остальные диалоги и короткое обычное предложение готового APK сохраняют
существующий shared builder.

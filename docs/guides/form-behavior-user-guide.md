# Вкладки и обязательные комментарии формы

Названия вкладок остаются сверху при прокрутке полей. Для перехода нажмите
название или сделайте взмах по содержимому: влево — следующая вкладка,
вправо — предыдущая. После перехода открывается начало вкладки, введённые
данные сохраняются. Внутри подписи, фото, текстового ввода и элементов со своей
горизонтальной прокруткой жест управляет этим элементом.

Обязательность может зависеть от ответа. Например, снятый чекбокс пункта аудита
делает комментарий к этому пункту обязательным. У поля появляется звёздочка.
Если отметить пункт снова, требование снимается, а введённый комментарий остаётся.
Постоянно обязательные поля сохраняют звёздочку при любом ответе.

Перед сохранением приложение проверяет все вкладки. Если не хватает значения,
показывает список пропусков и открывает первое поле. Выход с сохранением
проверяется так же. Пустота, пробелы и «Нет значения» не заполняют обязательное
поле; «не применимо» допустимо там, где предусмотрено справочником.

Условия работают без интернета. После изменения администратором обновите
проект и откройте новую форму: существующий черновик сохраняет прежние правила.
Сообщение о невозможности проверить условия означает, что форму нужно обновить
или передать администратору; введённые данные остаются в черновике.

Администратор задаёт правила отдельно для каждой NGFP, без изменения облачного
сервера. Для подготовки доступны сравнения значений, проверка пустоты и группы
«И»/«ИЛИ». [Формат и примеры](../architecture/conditional-form-rules.md).
Первый тестовый пример — форма «Аудит — вывозка» в группе 803.

Для выпуска 3.1.2.33 (227) App закрепляет полученные с сервера merge-коммиты maplib `4217869d0b983ccbe84bf8c6efc750c010eee5f3` и maplibui `2043d21b2d653dfc4d5412b955a552720be5209a`. Git-дерево каждой библиотеки совпало с деревом прежнего pin. EasyPicker остаётся на `74d0963d8b90bcdf80070b9f01ed453680fdc153`.

Сборка для ручной проверки использует итоговый App-коммит после squash-слияния. Full и Check-Publication проверяют этот комплект исходников. Подписанные APK передаются для ручной проверки с SHA-256 перед отдельным решением о публикации.
